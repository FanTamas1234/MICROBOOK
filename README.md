MICROBOOK – это клиент-серверное приложение для обмена книгами, построенное на микро-сервисной архитектуре. Пользователи могут делиться книгами, оставлять отзывы и находить новые произведения.

🛠 Технологии
Backend:
- Java 21 - в качестве языка программирования;
- Spring Boot 3.4.X - фреймворк на Java для разработки клиент-серверных приложений; 
- Spring Cloud - для реализации некоторых паттернов микросервисной архитектуры, таких как “Централизованная конфигурация”, “Регистр сервисов” и “API шлюз”;
- Keycloak  26.1.4 - для интеграции идентификации, аутентификации и авторизации;
- Gradle - система для автоматизации сборки, тестирования и контроля версий;
- PostgreSQL 17.2 - в качестве базы данных для сервисов с бизнес логикой;
- Docker - для контейниризации и оркестрирования сервисов;
- Kafka - для коммуникации микросервисов;
- Zookeeper - для хранения метаданных организации и работы Kafka; 
- Swagger - для документирования и тестирования API;
- Postman - также для тестирования API;
- ELK (Elasticsearch, Logstash, Kibana) - для реализации паттерна микросервисной архитектуры “Агрегация логов”.
📂 Структура проекта
Сервисы:
- User-service – управление пользователями;
- Exchange-service – обработка заявок на обмен книгами;
- Book-service – управление книгами и их принадлежностью пользователям;
- Gateway-service – API Gateway для маршрутизации запросов.

  🧠 Логика:
1.  Пользователь регестрируется и проходит авторизацию через User-service; 
2.	Пользователь создает заявку на обмен через /api/exchange/request;
3.	Exchange-service проверяет доступность книг через Book-service;
4.	При подтверждении обмена:
5.	Book-service обновляет владельцев книг.
Схема взаимодействия:
Клиент → Gateway → Exchange-service → (Kafka) → Book-service → (Kafka) → User-service
